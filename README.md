## ◇ 關於《時盡》

《時盡》不是單純的角色介紹網站。

它是一套會隨著閱讀進度逐步展開的 **互動式敘事／探索網站**。

玩家讀到哪裡，角色、世界觀與相關資料才存在到哪裡。

> **讀到哪裡，世界就存在到哪裡。**

未解鎖的內容不會以鎖頭、`???` 或空白卡片提示存在。  
在玩家尚未走到那個時間點以前，那些資訊就不應該出現在他的世界裡。

## ◇ 世界規則

### 時之沙漏

世界的時間如同一座巨大的沙漏。

最後一粒沙落下時，世界翻轉、重新開始。

每一次循環中，人物、過程與形式都可以不同。

但某些終局始終不變。

> **萬物重來，終局如一。**

## ◇ 家皇歿式

家式自創武學體系。

| 字訣 | 招式 | 核心 |
|---|---|---|
| **時** | 止刻 | 停止當下之刻 |
| **空** | 斷界移影 | 切開短暫時空裂隙，斷除距離 |
| **血** | 血迴 | 血能運轉與取命流程 |
| **弒** | 絕脈 | 終結生命之脈 |

### 家皇歿式・零

「零」不是單一招式。

它是時、空、血、弒四系在停滯的一瞬之內完成的複合運作。

零式解除後，時間會向家式討回代價。

> **零式之中，他幾乎站在時間之外。  
> 零式解除後，時間便向他討回代價。此即——「時蝕」。**

## ◇ 時印系統

時印是《時盡》網站的個人旅程系統。

不需要建立帳號。

每位進入世界的玩家都會擁有一段自己的旅程資料。

### 時印記錄

- 讀過的故事
- 遇見的角色
- 理解的世界觀
- 最後停留的位置
- 個人時印序
- 時印石片
- 光源色
- 本命刻紋
- 後續共鳴與時痕

當旅程被保存時：

> **此刻，已被時印記下。**

---

## ◇ 時印石片

> **時印石片，是時之沙漏破碎後留下的碎片。**  
> 它本來不屬於任何人。  
> 當一個人第一次留下時印，石片才會回應他的存在，接受他的光源色，並在表面與內部留下只屬於那個人的時印刻痕。  
> 之後，隨著他讀過的故事、遇見的人、理解的世界增加，新的時痕會一層一層留在同一枚石片上。  
> 它不是升級，也不是裝飾。  
> **它是在記住這個人走過的時間。**

### 十二母石

十二種母石對應 **十二時辰**。

每位玩家在正式「時空鑄印」時，由系統認定其中一枚。

母石一旦認主，就不再更換。

### 本命刻紋

每位玩家的刻紋由固定種子生成。

**同一個人，永遠是同一枚紋。**

目前刻紋系統包含：

- 十二母石獨立安全區
- 個人刻紋中心
- 尺寸與旋轉差異
- seed 固定生成
- Alpha 遮罩裁切
- 玩家光源色折光

核心定義：

> **個人時印刻紋 = 你是誰**  
> **後續時痕 = 你走過什麼**

## ◇ 角色圖誌

角色頁不再使用獨立「角色圖庫」。

每一名角色都擁有自己的 **角色圖誌**。

Drive 分類統一：

```text
人物
└─ 角色名稱
   ├─ 01-主視覺
   ├─ 02-圖誌
   ├─ 03-招式
   ├─ 04-細節
   └─ 05-其他
```

角色圖誌可以收錄：

- 情境圖
- 姿勢圖
- 特寫
- 武器互動
- 戰鬥畫面
- 影片

沒有素材時，整個區塊不顯示。

## ◇ Google Drive 媒體同步

正式同步函式：

```javascript
syncDriveMedia()
```

用途：

- 同步角色圖片
- 同步角色影片
- 辨識媒體所屬人物
- 辨識分類
- 自動提供前端角色頁使用

> `syncDriveImages()` 僅保留舊版相容。  
> 後續正式操作一律使用 `syncDriveMedia()`。

**世界不是一次被告訴你的。**
